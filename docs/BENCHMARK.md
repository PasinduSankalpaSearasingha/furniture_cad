# Factory benchmark protocol — awaiting approved source data

No approved factory drawing, measured part set, glass system or hardware installation specification was supplied. Synthetic test fixtures must never be used as factory profiles. The mixed-material sample uses illustrative dimensions, unapproved profiles and an empty hardware schedule; hardware is explicitly blocked rather than fabricated.

Before any production qualification, a qualified designer must supply the signed cabinet drawing revision, physical measurements and measurement uncertainty, stock thickness measurements, sheet/board data, joinery profiles with residual-wall criteria, glass and retention specifications, hinge and connector installation drawings, and application-specific load/stability requirements.

Record each benchmark part ID against its measured finished size, blank size, stock source, grain, machined features, joint interfaces and drawing number. Compare the exported STEP solids, all drawing dimensions, cutting schedule, BOM and hardware quantities against the signed source. Record applicable acceptance tolerances from that source; this repository supplies no default acceptance tolerances.

Assemble a prototype. Document fit, squareness, door movement, glass restraint, fastening and relevant structural/safety tests with qualified signoff. Link evidence and hashes to the exact design revision. Repeat after template, material, hardware or parameter-envelope changes. Factory release remains unavailable until missing geometry, shop documents and these checks are implemented and qualified.
