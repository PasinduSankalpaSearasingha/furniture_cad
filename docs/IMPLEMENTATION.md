## Common furniture library and estimated CAD

The library adds 43 templates across seating, tables, storage, beds, sofas, screens and racks. AI estimation is a distinct review-only mode: strict parameter output, per-value provenance, immutable checkpoint/revision hashes, automatic CAD queueing and advisory review of the real exports. Curved rails are bounded Bezier sweeps; legs use tapered/splayed curved lofts; sculpted seats use a shallow dish. The legacy physically verified cabinet path retains its evidence gates. Source-unit GLB tessellation avoids slow scaled-spline meshing, contoured post/rail contacts avoid nonmanifold tangent edges, and zero-area binary STL facets are omitted without changing STEP geometry.

The full suite passed **168 tests with one optional live test skipped**; see test-results.xml. The dedicated furniture suite passed 58 tests. A separate live run reused the existing chair observations and called the configured design/review models to create an estimated 620 x 600 x 820 mm armchair. The corrected export is revision 2 of the same chair project, with no additional paid AI call. Its STEP has nine solids, GLB has nine named components in metres, and STL is watertight with the expected millimetre envelope. This is one review example, not a reconstruction-accuracy or manufacturing qualification benchmark. See FURNITURE_LIBRARY.md.


## Image-first reconstruction

The current studio removes the template picker and asks for uploaded furniture photos plus optional values. Photo analysis supplies relevant input definitions with blank values and estimated placeholders. The PHOTO workflow creates an independent component plan with named parameter expressions, custom Bezier outlines/sweeps, lofts and eight bounded shape primitives. It preserves supplied values, estimates missing ones, preflights real CAD and permits one constrained correction. After export, advisory review compares both the original photograph and the actual generated STEP preview. Saved legacy designs retain their existing readers/generators. The full suite passes 195 tests with one optional live test skipped; 26 focused photo tests and desktop/mobile upload/optional-input browser checks pass. See PHOTO_RECONSTRUCTION.md.
